# 练记 LiftLog

离线优先、无需账号的力量训练 PWA。适用于手机，尤其是 iPhone Safari「添加到主屏幕」使用。

## 功能

- 胸 / 背 / 腿 / 肩四分化模板；新建、编辑、复制、删除计划。
- 自由训练；动作、组数、重量（kg）、次数、完成标记与训练备注。
- 同名动作自动带入最近一次训练数据；误触完成可以撤销。
- 组间休息计时，按结束时间恢复；可手动增减休息时间。
- 本周训练进度、完成组数、容量、时长；历史筛选与详情。
- IndexedDB 本地保存、JSON 完整备份与恢复、CSV 历史导出。
- 离线应用缓存、更新提示、可选亮屏、同一浏览器多标签页单写入保护。
- 无第三方脚本、字体、CDN、统计服务或训练数据上传接口。

## 本地运行

需要 Node.js 18 或更新版本（推荐受支持的 LTS）。没有 npm 依赖，无需 `npm install`。

```sh
node server.mjs
```

打开终端打印的 `http://127.0.0.1:4173/`。本地服务器默认只监听本机。
静态应用源文件位于 `docs/`，可直接部署到 GitHub Pages。

## GitHub Pages

在仓库 Settings → Pages 中选择 Deploy from a branch，分支 `main`，目录 `/docs`。
应用采用相对路径，适用于项目子路径，例如 `https://USERNAME.github.io/liftlog/`。
自有域名不是必需条件。服务器发布的仅是程序资源，不是用户训练数据。

## iPhone 使用

1. 在 Safari 打开正式 HTTPS 地址，选择分享 → 添加到主屏幕。
2. 从主屏幕图标启动，联网等待顶部显示「离线已就绪」。
3. 再关闭网络验证可以启动、记录一组并刷新保留。
4. 在设置里每周导出 JSON 完整备份，确认保存到「文件」或 iCloud Drive。

## 重要边界

- 训练数据属于当前网址、浏览器和设备，不会自动同步到电脑、GitHub 或另一部手机。
- 不同网址或浏览器的记录可能相互隔离。更换地址前请导出并导入 JSON。
- 网站缓存被清除、重装浏览器或更换设备时，本地记录可能丢失；持久化申请也不能代替备份。
- CSV 用于查看和分析；恢复应用状态请用 JSON。恢复会替换现有本地数据，操作前请导出旧数据。
- 休息计时在返回应用时可以校准，但锁屏或后台的声音提醒不保证触发，不是系统闹钟。
- 首次安装与应用更新需要联网；已完成缓存后，日常记录可离线进行。
- 主屏幕安装、iOS 省电/锁屏行为和网络可达性仍需在真实 iPhone 上测试。
- 模板仅为记录示例；不是医学或个性化训练建议。0 kg 可用于自重动作，统计容量只计外部负重。

## 实现

使用原生 ES Modules、CSS、IndexedDB、Web App Manifest 和 Service Worker。无构建依赖。
升级静态资源时同时递增 `docs/sw.js` 的缓存版本。新版本准备好后，在应用中保存并更新。
页面不会自动刷新正在进行的训练。导入备份进行结构和数值范围校验，文字输出做 HTML 转义，CSV 防公式注入。

本地测试、截图、网络测量记录和私人备份不提交到公共仓库。
