# 练记 LiftLog

离线优先、无需账号的力量训练 PWA。适用于手机，尤其是 iPhone Safari「添加到主屏幕」使用。

## 功能

- 胸 / 背 / 腿 / 肩四分化模板；新建、编辑、复制、删除计划。
- 内置 140 个中文动作，支持中文 / 英文 / 别名搜索，以及 17 类主要部位（含 4 类宽泛部位）和 13 类主要器材交叉筛选；无运行时动作库 API 依赖。
- 训练中添加动作、计划中添加或替换动作，均保留手动输入；计划按动作名称、组数 / 次数 / 重量两行编辑，每张卡片独立标注单位。
- 自由训练；动作、组数、重量（kg）、次数、完成标记与训练备注。
- 同名动作自动带入最近一次训练数据；误触完成可以撤销。
- 新动作默认 4 组；训练中可改动作名称和各组数据，每组独立选择负重 / 自重 / 辅助重量，支持递增 / 递减及自定义子组。
- 动作库显示最近完成重量；动作历史支持独立曲线及逐组明细，历史训练可新建或覆盖计划。
- 组间休息计时，按结束时间恢复；可手动增减休息时间。
- 本周训练进度、完成组数、容量、时长；历史筛选与详情。
- 当前训练的整数进度百分比；添加动作时可选择插入位置，训练中与计划编辑器均可上移／下移动作。
- 可维护年龄、体重、训练强度，显示活动消耗与含静息总消耗的粗估值；支持暂停计时。
- 历史默认显示全部月份，列表日期使用本地时间、当年省略年份；支持单条／批量删除，以及详情内删减动作或某一组（需确认）。
- IndexedDB 本地保存、JSON 完整备份与恢复、CSV 历史导出。
- 离线应用缓存、更新提示、可选亮屏、同一浏览器多标签页单写入保护。
- 无第三方脚本、字体、CDN、统计服务或训练数据上传接口。

## 本地运行

需要 Node.js 18 或更新版本（推荐受支持的 LTS）。没有 npm 依赖，无需 `npm install`。

```sh
node server.mjs
```

打开终端打印的 `http://127.0.0.1:4173/`。本地服务器默认只监听本机。
静态应用源文件位于 `docs/`，可直接部署到 GitHub Pages。

## GitHub Pages

在仓库 Settings → Pages 中选择 Deploy from a branch，分支 `main`，目录 `/docs`。
应用采用相对路径，适用于项目子路径，例如 `https://USERNAME.github.io/liftlog/`。
自有域名不是必需条件。服务器发布的仅是程序资源，不是用户训练数据。

## iPhone 使用

1. 在 Safari 打开正式 HTTPS 地址，选择分享 → 添加到主屏幕。
2. 从主屏幕图标启动，联网等待顶部显示「离线已就绪」。
3. 再关闭网络验证可以启动、记录一组并刷新保留。
4. 在设置里每周导出 JSON 完整备份，确认保存到「文件」或 iCloud Drive。

## 重要边界

- 训练数据属于当前网址、浏览器和设备，不会自动同步到电脑、GitHub 或另一部手机。
- 不同网址或浏览器的记录可能相互隔离。更换地址前请导出并导入 JSON。
- 网站缓存被清除、重装浏览器或更换设备时，本地记录可能丢失；持久化申请也不能代替备份。
- CSV 用于查看和分析；恢复应用状态请用 JSON。恢复会替换现有本地数据，操作前请导出旧数据。
- 休息计时在返回应用时可以校准，但锁屏或后台的声音提醒不保证触发，不是系统闹钟。
- 首次安装与应用更新需要联网；已完成缓存后，日常记录可离线进行。
- 主屏幕安装、iOS 省电/锁屏行为和网络可达性仍需在真实 iPhone 上测试。
- 模板仅为记录示例；不是医学或个性化训练建议。0 kg 可用于自重动作，统计容量只计外部负重。

### v1.5 本机自定义动作库与收纳式逐组编辑

- 训练卡片移除独立负重标签，编辑与删除并排；逐组设置以单个「类型」按钮展开组型和负荷，重量、次数在小屏仍同排。

- 同名匹配仅忽略两端空白，不自动合并近似名称。历史重量仍从实际已完成记录读取，不把编辑草稿当作历史；删除历史后显示值同步重新计算。
- 本地数据和 JSON 备份升级至 v5，兼容读取 v1–v4，并为已有计划、训练和历史中的自定义名称建立本机条目。旧版应用不支持导入 v5 备份，更新前建议先导出备份。

### v1.1 能耗估算与数据升级

参考联网核验的 [2024 Adult Compendium](https://pacompendium.com/) 和 [力量训练分类](https://pacompendium.com/conditioning-exercise/)（核验日期 2026-10-12）：

- 常规多动作、8–15 次力量训练：3.5 MET，代码 02054；高强度举铁：6 MET，代码 02050。默认使用 3.5，不按负重或容量自动推断强度。
- 总消耗约为 `MET × 体重 kg × 训练小时`；活动消耗约为 `(MET − 1) × 体重 kg × 训练小时`，采用 1 MET 约等于 1 kcal/kg/hour 的定义，结果取整。
- 年龄用于检查成人模型的 19–59 岁适用范围，不凭空添加年龄、身高或性别修正。范围外不输出本模型估算。
- 整段训练时间包含普通组间休息，排除手动暂停；暂停也冻结组间休息倒计时。长时间中断请暂停，否则可能高估。
- 不是心率/代谢测量，不额外加算训练后耗氧；个体误差可能较大，不应据此精确补吃热量。删减历史组数不改变基于时长的估算。
- 每场训练保存独立的体重、年龄、强度、算法版本快照；修改默认参数不改写已结束的历史。旧记录没有快照时显示未估算，不反推历史体重。
- 本地数据/备份格式为 v2，兼容导入与读取 v1；保留已有 ID、动作顺序及训练内容。不会自动清空旧数据。不支持把 v2 备份导入旧版应用。
- 身体参数初始为空，只由用户在设备上填写；公共代码不包含用户的个人参数或训练记录。

### v1.1.1 手机交互调整

- 数字输入框为 0 时，聚焦后临时留空，直接输入即可替换；未输入就离开会恢复 0，非零数值不会自动清空。训练与计划编辑共用此行为，记录仍按合法数字保存。
- 休息卡片位于训练内容前部，滚动时吸附顶部；保留单指原生滚动，卡片内可增减时间，暂停／结束状态始终可见。顶部避让 `safe-area-inset-top`，不写死设备型号或屏幕尺寸。
- 放大动作说明、表头、历史日期、按钮、导航等常用文本；手机输入字号至少 16px，训练数字 18px。
- 按自用需求关闭双击／双指页面缩放，使用 `touch-action: pan-x pan-y`、viewport 限制与 Safari 手势事件兜底；不禁用系统辅助功能或修改设备设置。禁用触摸缩放会减少低视力用户的放大手段，本版本是用户明确选择的自用交互。
- 浏览器或辅助功能设置仍可能覆盖页面的缩放限制，真实 iPhone Safari／主屏幕 App 效果需实测；模拟触摸测试不等于 iPhone 18 Pro 真机验证。参考 [MDN touch-action](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/touch-action)、[viewport 限制](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/meta/name/viewport) 与 [WebKit gesturestart](https://developer.mozilla.org/en-US/docs/Web/API/Element/gesturestart_event)。

### v1.2 动作库与计划编辑

- 根据 [Free Exercise DB](https://github.com/yuhonas/free-exercise-db) 的公开数据整理，固定来源版本并保留原始动作 ID；按 [ACE 动作库](https://www.acefitness.org/resources/everyone/exercise-library/) 的部位与器材分类思路设计筛选，未复制 ACE 教程或图片。许可与修改范围见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
- 包含胸、背、肩、肱二头肌、肱三头肌、前臂、腹部 / 核心、臀、大腿前侧 / 后侧 / 内侧、小腿、全身复合。部位筛选以主要训练目标为准，搜索也可匹配辅助肌群。器材按主要器材归类，不表示不需要平凳或支架。
- 选择器内置于应用缓存，完成更新后离线搜索与选择；仅手动点击来源链接才会访问外站。不发送训练记录或搜索内容。
- 选择 / 取消动作库会保留计划草稿或添加表单；替换动作不重置已编辑的组数、次数和重量。从库添加优先填入空白动作行。
- 保留既有模板名称、历史与备份格式。仍按同名动作带入最近记录；自定义改名后不会自动合并到另一个名称的历史。
- 动作库侧重按次数记录的力量动作，不把平板支撑、跑步等计时项目误记成次数。难度标签取自数据源，并不代表个人适用性；默认组次只是输入初值。
- 编辑计划的训练分类新增手臂、核心、臀、小腿、上肢、下肢，不局限四分化。

### v1.2.1 顶部计时与动作库样式

- 移除界面内的数据来源下拉区域；项目根目录的 THIRD_PARTY_NOTICES.md 与数据文件中的出处信息保留。

### v1.3.0 逐组记录与动作趋势

- 训练动作卡片增加直接上移 / 下移按钮；排序保留每组参数、完成状态与休息计时。顶部与底部统一使用“完成训练”，放弃训练使用同尺寸的矩形描边按钮。
- 新增动作默认 4 组。完整名称匹配（忽略首尾空格）最近有完成内容的同名动作时，带入实际完成的组数、各组重量、次数及子组结构；未完成部分不带入。手动输入及动作库入口均支持。组数、次数、重量仍可自行修改。
- 动作库显示最近已完成重量范围和组数；自定义且完成过的动作也会加入本机个人动作列表。重量从训练历史及本次已完成内容即时派生，不上传、不单独维护可能过期的副本；删减记录后同步更新。
- 重量类型包括负重、自重、辅助重量。自重只记录次数，辅助重量不作为实际举起的重量计入容量。原有未标明类型的记录继续按负重解释，不擅自改写历史含义。
- 普通组、递增组、递减组、自定义子组可逐组设置。复合组最多 8 个子组，可用基数、变化值生成，再逐项调整重量和次数。子组独立勾选，全部完成才记为一个完整组并启动休息；只完成部分子组也可保存，次数 / 容量仅统计完成部分。
- 历史页和动作卡片提供动作趋势，按完整名称与重量类型分别显示最近 30 次已结束训练。负重 / 辅助重量采用各完成组等权平均；复合组先平均已完成子组，再与其他组求平均。自重显示每次完成总次数。逐组明细可展开，未完成部分不参与曲线。
- 历史详情可保存为新计划，或确认后覆盖一个现有计划的动作及备注（保留目标计划名称、分类）；不修改历史。仅保留已完成部分，保留顺序、特殊组和逐组差异。
- 数据格式升级为 v3，兼容 v1 / v2 备份与进行中的训练。v3 备份不能导入旧版本应用；更新前仍建议导出备份。CSV 增加重量类型、组类型及子组序号。
- 计划中的“逐组 / 特殊组设置”可以维护每组参数；快捷修改次数或重量会统一应用到各组。开始训练时，兼容重量类型的同名近期记录仍优先用于重量回填。

### v1.3.1 弹窗交互与手动热量

- 隐藏各页面与弹窗的滚动条外观，保留触摸、鼠标滚轮和键盘滚动。打开弹窗时锁定背景页面，关闭后恢复原滚动位置。
- 逐组设置及动作库的关闭、取消、返回操作只返回上一层；保留上一级计划草稿与滚动位置。逐组修改需点“保存设置”后才应用，关闭不保存该层修改。
- 完成训练时可选填手动热量，并区分活动热量与含静息的总热量；历史详情中可再次修改。留空使用原有自动活动热量估算，未设置身体参数则不编造估算值。手动数值独立保存，不改写原始估算参数，也不沿用到下一次训练。
- 手动热量随本机记录和 JSON 完整备份保存；CSV 仍用于逐组训练明细。备份格式保持 v3，更新前仍建议导出备份。
- 动作库只展示中文名称，英文与别名仍可用于搜索；历史重量精简为“上次 · 3组 · 60–65 kg”等单行提示。
- 已完成桌面浏览器手机尺寸、模拟触摸、离线与旧版本更新回归；iPhone Safari / 主屏幕应用的实际手感仍需真机验证。

### v1.3.2 逐组设置与四组默认计划

- 相关入口和子页面统一为“逐组设置”。每组仅提供“递增 / 递减”两个互斥切换按钮；未选时为普通组，再次点击已选按钮恢复普通组并保留首个子组的重量和次数。涉及已完成记录时先确认，子组仍可逐项手动编辑。
- 移除组类型下拉框、“自定义”选项及“参数”文字；普通组采用重量 / 次数双栏，子组编号与输入框垂直对齐。旧版自定义子组仍保留并可继续编辑，不静默重写训练记录。
- 新安装的胸 / 背 / 腿 / 肩默认计划，每个动作均为 4 组。已有记录按计划名称、分类及完整默认动作集合识别原预设，首次升级时同步为 4 组；保持动作顺序及已有重量 / 次数，逐组计划不足 4 组时复制末组补齐，超过时保留前 4 组。
- 默认计划调整只执行一次，之后手动修改组数不会被刷新覆盖；重命名或替换了动作的自定义计划、历史记录、进行中的训练均不调整。升级标记随 JSON 备份保存，导入未升级旧备份时执行相同的默认计划调整。

### v1.3.3 点击热量卡片编辑与按钮统一

- 完成训练时点击估算卡片，即可直接填写总热量（含静息，kcal）；移除热量类型下拉框和默认展开的输入栏。手动修改统一保存为总热量，清空输入恢复自动估算。
- 仅查看卡片或打开编辑而未修改，不会把自动估算变成手动值，也不会重新解释旧版的活动热量记录。旧记录保持原口径，重新填写后才按总热量保存；取消不改动记录。
- 历史详情删除改为圆角矩形描边按钮，列表删除增加矩形边框；操作按钮共用圆角尺寸并禁用平台原生按钮外观。修复批量删除的小尺寸样式覆盖危险色的问题；筛选、导航等控件仍保留各自语义。

### v1.3.4 页面留白与一体化训练进度

- 手机各页面底部按导航栏实际高度、安全区和额外 32px 留白避让；侧栏布局也保留底部余量，最后一张卡片不再紧贴导航栏。导航或休息卡片尺寸变化时同步更新布局。
- 历史列表与概览最近记录去掉容量显示；保留训练名称、完成组数和简短日期。当年显示月 / 日，跨年保留年份，历史列表继续显示时分，完整日期在详情中保留。仅精简展示，不删除容量或日期数据。
- 训练整体进度融入吸顶休息卡片：沿卡片外框从顶部顺时针填充，并显示整数百分比及已完成 / 总组数。该外框表示整场训练进度，不是休息倒计时；全部子组完成才计为一组，勾选、撤销和增减组数会同步更新。
- 暂停 / 继续合并到休息卡片内，暂停时训练与休息计时同时冻结；取消独立训练进度卡片和“调整顺序”入口，动作卡片上的上移 / 下移按钮继续保留。

### v1.4.0 紧凑动作编辑与后续组联动

- 训练卡片统一使用“编辑”，可修改动作名称和逐组数据；不再单列“历史”按钮，动作趋势仍可从历史页进入。训练中改名只修改本次动作，不改写计划或以前的记录。
- 普通组在常用手机宽度下一行显示组号、增 / 减 / 自 / 辅、重量、次数及移除按钮；窄屏允许两行。增 / 减互斥，再点恢复普通组；自 / 辅互斥，再点恢复负重，未选时为负重。递增递减的子组在下方展开，可编辑步长、数量或单个子组。
- 取消“应用为统一普通组”按钮。填写统一重量 / 次数即更新下方数据，组数离开输入框后同步增减；保留各组类型、差值和标识。训练中统一修改仅更新未完成部分，减少组数涉及已完成内容时仍需确认。
- 训练页面或训练动作编辑框中修改某组重量 / 次数，会同步同一动作后续未完成组及子组。已完成的后续内容和其他动作不变；若直接编辑已完成组，其自身记录会更新。重量只在相同重量类型间联动，自重不写入外部负重；次数可跨类型联动。复合组保留相对重量差，数值限定在 0–2000 kg。
- 计划编辑的逐组修改不联动后面的其他组；统一参数仍可批量修改。只聚焦零值后离开不会触发联动，输入多位数时以聚焦前数据为基准，避免中间输入导致递增递减差值丢失。
- 容量仅计算实际负重组；历史曲线按每组重量类型分开计算，辅助与自重不混入负重平均值。最近动作回填、历史转计划、CSV 与 JSON 均保留逐组类型。
- 数据格式升级为 v4，兼容 v1 / v2 / v3；旧记录缺少逐组类型时继续沿用原动作类型。v4 备份不可导入旧应用。更新前请导出备份，切勿清除网站数据。
- 精简页面英文小标题、操作说明与重复提示；保留备份风险、删除确认、能耗口径等必要信息。已通过桌面浏览器多尺寸、模拟触摸、离线和旧版升级检查；iPhone 真机仍需验证。

### 技术实现

使用原生 ES Modules、CSS、IndexedDB、Web App Manifest 和 Service Worker。无构建依赖。
升级静态资源时同时递增 `docs/sw.js` 的缓存版本。新版本准备好后，在应用中保存并更新。
页面不会自动刷新正在进行的训练。导入备份进行结构和数值范围校验，文字输出做 HTML 转义，CSV 防公式注入。
